# Rupkala
RupKala is an AI-powered digital marketplace that empowers Indian artisans by providing intelligent product management, multilingual support, customer engagement, and business analytics through a modern full-stack web application.


# 🎨 RupKala

> Empowering Indian Artisans with AI, Digital Commerce, and Smart Business Tools.

RupKala is an AI-powered full-stack marketplace designed to help Indian artisans showcase, manage, and sell handcrafted products digitally. The platform combines modern web technologies with AI-assisted tools to simplify product creation, improve customer engagement, and provide actionable business insights.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Hussainbohra786/rupkala.git
```

Move into the project

```bash
cd rupkala
```

Install dependencies

```bash
npm install
```

Run the application

```bash
npm run dev
```
